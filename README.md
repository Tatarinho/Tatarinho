### Currently

**Software Engineer at Commerzbank Digital Technology Centre Poland.**

I design and maintain cloud-native Python microservices that bring AI/LLM capabilities
into enterprise banking systems. Most of that work happens on **Google Cloud Platform** —
Vertex AI for the model layer, BigQuery for analytics, with the surrounding services
provisioned as code through Terraform and run on Kubernetes.

The problems I spend my time on are the ones that show up once an LLM has to behave
like a dependable part of a regulated system: fault-tolerant asynchronous pipelines,
structured logging and error handling that make failures traceable, callback mechanisms
that survive partial outages, and integrations that hold up to enterprise security and
auditability requirements.
